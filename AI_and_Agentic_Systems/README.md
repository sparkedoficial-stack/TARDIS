# AI_and_Agentic_Systems

Sistemas agénticos autónomos, enjambres cognitivos MoE, autorreflexión y evolución continua.

## Subsistemas y Componentes Principales:

- **tardis_agent_colony.py**: Modelo lógico y comportamiento autónomo distribuido.
- **tardis_autoprogrammer.py**: Componente de alta eficiencia.
- **tardis_curiosity_debater.py**: Componente de alta eficiencia.
- **tardis_scientific_researcher.py**: Componente de alta eficiencia.
- **test_tardis_agent_colony.py**: Modelo lógico y comportamiento autónomo distribuido.
- **test_tardis_autoprogrammer.py**: Componente de alta eficiencia.
- **youtube_learner.py**: Componente de alta eficiencia.

## Requisitos e Integración
Los módulos operan bajo el stack soberano de Linux (x86_64), integrando aceleración por GPU y telemetría de bajo nivel.
